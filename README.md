# Tickloop plugins

The plugins Tickloop publishes for agents that install Claude-format plugins.

| Plugin | What it does |
| --- | --- |
| [`tickloop-artifacts`](plugins/tickloop-artifacts/README.md) | Pages, Docs, Slides, Designs, Design systems, Data dashboards and Motion films kept in your Tickloop account, with the Skills to make them. |

Add the marketplace in Claude Code with `/plugin marketplace add tickloopai/tickloop-plugins`, or in Codex with `codex plugin marketplace add tickloopai/tickloop-plugins`, then install a plugin from it as its README describes.
